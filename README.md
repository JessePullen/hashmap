# Project: Hash Map

## About the Project

This is a HashMap project as part of "The Odin Project". Practicing my skills with data structures, I had to create a HashMap from scratch using JavaScript. The project involved implementing hash functions, handling collisions with buckets, and creating methods to add, update, remove, and retrieve key-value pairs. I also implemented dynamic resizing and rehashing when the load factor became too high.

## Skills Practiced

- Data Structures
- Hash Functions and Hash Maps
- Collision Handling with Buckets
- Key-Value Pair Management
- Dynamic Resizing and Rehashing
- Handling Edge Cases and Errors
- Testing with Jest
- Test-Driven Development (TDD)
